# 凡人 · 角色造型集

[打开在线造型集](https://magic-xu.github.io/fanren-character-gallery/)

《凡人修仙传》八位角色的 Q 版立体手办二创，共十六张成图。每位角色包含全身主视图与四视图，采用浅灰棚拍风格。

- 主视图 / 四视图切换，点击图片放大。
- 单张原图与完整套图下载。
- [造型与来源](造型与来源.md)、[生成提示词](生成提示词.md)及韩立参考对照。

角色：梅凝、韩立、南宫婉、紫灵、元瑶、银月、陈巧倩、慕沛灵。

## 本地预览

在仓库目录运行 `python3 -m http.server 8765`，访问 `http://127.0.0.1:8765/`。

## 发布

GitHub Pages 从默认分支 `codex/publish-gallery` 的根目录发布。推送更新后自动部署，无需构建步骤或后端服务。

参考资料与补全范围见“造型与来源”。四视图用于展示，包含生成与补全细节。
